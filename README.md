# ZenBox preview

## Run it on your Omarchy laptop

Open a terminal and paste:

```bash
curl -fsSL https://raw.githubusercontent.com/thevidarbob/zenbox-preview/main/zenbox/get-zenbox.sh | bash
```

A window called Inbox should open. After that, Super+Shift+Z summons it.

Browser-only preview: https://htmlpreview.github.io/?https://raw.githubusercontent.com/thevidarbob/zenbox-preview/main/zenbox.html
